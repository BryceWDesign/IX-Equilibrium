# Changelog

## 0.1.0, 2026-10-08 UTC

First implemented research release of the Equilibrium supervisory coordination
language. Includes a lexer, source diagnostics, immutable AST, dimensional
checker, checked JSON IR, static interval summaries, deterministic interpreter,
sensor quorums, conservative uncertainty predicates, bounded parameter
adaptation, actuator envelopes and slew limiting, state machines, host grants
and action-bound reviews, a durable pre-dispatch evidence journal, independent
integrity verification, deterministic replay, fault campaigns, finite input
exploration, an offline report and an authenticated UDP sensor bridge.

This release does not claim native code generation, hard real-time execution,
robot dynamics validation, ROS 2 integration, certified safety, EEG decoding,
AGI, or distributed actuator transactions.
